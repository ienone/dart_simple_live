## 关注数据兼容性

关注记录以 `tags` 保存多标签，`tag` 为首个标签的旧版兼容投影；置顶、手动顺序和元数据版本随记录持久化。标签定义有独立版本与删除墓碑。只有显式添加标签产生的新定义可以重新启用已删除标签，置顶或排序不能重新启用它。

文件导出仍是 JSON 关注数组。非空数组的首条记录附带 `tagDefinitions`，包含空标签与删除墓碑；导入与 LAN、远程同步共用校验和合并流程，旧数组仍可导入。旧数据缺少新增字段时保留本机已有值；缺少定义的数据不能重新启用本机已删除的标签。

空关注数组不插入虚构记录，因此文件格式无法单独传递空标签或墓碑；需要保存这些独立标签时使用 LAN 或 WebDAV 的标签资源。
